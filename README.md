# 🎓 Student Performance Predictor

## 📌 Overview
This project predicts student performance using Machine Learning based on factors like study hours, attendance, and previous scores.

## 🚀 Features
- Predict student scores
- Identify weak areas
- Provide improvement suggestions

## 🛠️ Tech Stack
- Python
- Scikit-learn
- Pandas
- Flask (for web app)
